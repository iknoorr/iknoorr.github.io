# Iknoor Kaur: Personal Portfolio

A personal portfolio website built by hand with HTML, CSS and JavaScript, hosted free on GitHub Pages.

**Live site:** https://iknoorr.github.io

## About the site

A bold cream-and-red layout with oversized lowercase headings, built around my own photographs.

- **Photo arc:** my photos sit along a curved arc on the home page.
- **Things I could talk about for hours:** tap a topic to see what I'd say.
- **Through my lens:** a scattered set of my photographs.
- **A question for 3 a.m.:** a button that gives you a random late-night question.
- **3 a.m. mode:** a dark theme toggle, named after the conversations I love having at 3 a.m.
- **Live clocks:** the current time in Mumbai and New York.

## Built with

- HTML, CSS and vanilla JavaScript (no frameworks, no templates, no site builders)
- Fonts from Google Fonts: Inter Tight, Inter and Caveat
